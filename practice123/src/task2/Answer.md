# exception checed
1. Отсутствкющий файл (FilrNotFoundExpextion/IOException) -
Внешняя среда, вызывающий обязан решить (Создать, заменить, сообщить)
2. Сетевой отказ (IOException) -
Внешнее транзитное условие, нужна политика retry-сообщения

# exception uncheked

1. Неверный оргумент метода (IllegalArgumentException) -
Программист может проверит до вызова, проверить компилятором избыточно
2. Нарушение состояния (IllegalStateException) -
Ошибка порядка вызовов/логики - виноват кот (мяу!)

# Другой результат
1. Ошибка конфигурации (fail-fast при старте) -
Лучшу упасть на bootstap, чем кидать во время работы часто uncheked/ExpectionInInitializerError

# Невозможность востоновления
1. Недостаток памяти (OutOfMemoryError) Error, не Expection. Ловить не льзя, только коректно завершится
